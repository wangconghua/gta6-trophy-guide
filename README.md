An offline static guide to all 55 GTA 6 trophies: a tracker with progress saved locally, filters by type and grade, search, a spoiler toggle, detail popups with sources and personal notes, a six-stage road-to-platinum roadmap, a missables page, a Next Up planner, export/import, and light/dark themes. Every trophy has a short self-written guide; no unverified locations or steps are invented.

## Run it

Open `app/index.html` in a browser — no build step, no network needed.
